## 这是什么

PrismWall 把你散落在各个文件夹里的照片和视频，变成一面可沉浸浏览的媒体墙——**全程不联网、不上传、不要任何网络权限**。

它不是又一个"相册"：它尊重你的文件夹组织方式，支持按时间、按文件夹、按类型自由浏览，内置多视频同屏对照播放，是为**摄影师、视频创作者、设计师和所有在意隐私的人**打造的本地媒体工作台。

## 特性

### 🖼 沉浸式媒体墙
- 时间线缩略墙，10 万级文件流畅滚动
- 点击放大浏览，捏合缩放，信息条展示 EXIF（相机/镜头/参数）
- 全屏轮播，交叉淡入淡出

### 🎬 多视频同屏对照（同类软件罕见）
- 最多 9 路视频同屏，同步播放偏差 < 5ms
- 焦点式控制：声音只属于焦点视频，Tab/数字键切换
- 宫格 / 一大多小布局切换，主时间轴统一拖动
- 运动动作对比、多机位素材审阅、拍摄现场回看

### 📁 为文件管理而生（不只是相册）
- **范围 × 类型 × 分组** 三维自由组合：
  - 范围：图库 / 收藏 / 任意来源文件夹
  - 类型：全部 / 只看照片 / 只看视频
  - 分组：按时间 / 按文件夹 / 不分组
- 进某个来源文件夹默认按其内部文件夹结构展示，绝不打乱你的组织
- 收藏标记、类型过滤、卡片密度调节（⌘+/⌘-）

### 🔒 隐私是架构，不是口号
- **不申请任何网络权限**——用系统工具即可验证
- 索引、缩略图、设置全部存于本机应用沙盒
- 删除/移除来源绝不触碰你的原始文件
- 发布包经过 6 项自动化隐私审计（文件白名单/用户名路径扫描/零网络验证等）

### ⌨️ 全键盘操作
- 方向键浏览、空格播放、回车进入、Esc 逐级返回
- `?` 随时呼出快捷键速查
- 完整支持"减少动态"辅助功能设置

## 下载安装

从 [Releases](../../releases/latest) 下载 `PrismWall-1.0.0-arm64.dmg`，然后：

1. 打开 DMG，将 `PrismWall.app` 拖入「应用程序」文件夹
2. 首次打开：双击后若提示"无法验证开发者"，打开 **系统设置 → 隐私与安全性**，拉到底部点 **「仍要打开」**（仅首次需要；也可在终端执行 `xattr -cr /Applications/PrismWall.app`）

> 采用 MIT 协议完全开源免费，没有付费墙，也不会有广告。

## 隐私承诺

| 承诺 | 验证方式 |
|---|---|
| 无任何网络权限 | `codesign -d --entitlements` 无 network 项 |
| 索引与缓存全部本地 | 数据仅存于 `~/Library/Application Support/PrismWall/` |
| 移除来源不删文件 | 只移除索引记录，磁盘文件零改动 |
| 发布包可审计 | 每次发布自动执行 6 项隐私自检（文件白名单/敏感字符串/零网络等） |
